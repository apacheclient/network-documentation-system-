# Device Naming Standards

## Purpose
Consistent naming makes the network easier to manage and troubleshoot.

## Naming Format

General Format:
`function-location-number`

## Examples

| Device Type     | Example Name         | Explanation                     |
|-----------------|----------------------|---------------------------------|
| Core Switch     | core-switch-01       | Main/core switch                |
| Access Switch   | access-switch-01     | Switch for end-user devices     |
| Router          | edge-router-01       | Internet edge router            |
| Access Point    | wifi-ap-lobby        | AP location included            |
| Firewall        | firewall-01          | Edge security device            |
| Server          | file-server-01       | Role-based server name          |

## Rules
- Use lowercase letters only
- Use hyphens `-` instead of spaces
- Keep names short but descriptive
- Numbers are two digits (01, 02, 03…)
- Location can be added when helpful (lobby, floor2, etc.)
